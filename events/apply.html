Security & Storage

  • Private Storage: Submissions and pitch decks are stored in isolated, access-controlled buckets.
  • Supported Files: PDF presentations, Word documents (.docx), and high-res images (.png, .jpg).
  • Size Limit: Max 15MB per uploaded file. Up to 5 files per application.
  • Row Level Security: Submissions are readable only by authorized club mentors and administrators.

Review Process

  1. 1. Submission Received

    You'll receive an instant confirmation reference ID.

  2. 2. Committee Verification

    Payment UTR is verified & mentors review project materials.

  3. 3. QR Ticket Pass Issued

    Accepted attendees receive a dynamic QR Admission Pass.
